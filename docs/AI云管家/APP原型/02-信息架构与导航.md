> 定"哪一页属于哪一层、从哪进、回哪去、谁能看见"。逐页细节在 `04-逐页交互清单.md`，跨页交互规则在 `05-全局交互约定.md`。

|---|---|---|---|---|

| 4 | 社区 | 双人 | `22 社区` | 四板块信息流（P2，规划中） |

- 底栏高 83（含安全区），图标 23、文字 11、选中态品牌蓝 + 下方 4px 圆点，未选 `#86909C`。
- Tab 切换保留各 Tab 内栈（A→详情→切到 B→切回 A 仍在详情）；**重复点当前 Tab = 回该 Tab 根页并滚到顶**。

## 2. 扫一扫（全局单一入口）

**入口：主页顶栏右侧固定「扫一扫」图标**，与右侧「消息」并列，不进宫格、不占右上胶囊安全区。二级页导航栏只保留返回，不重复放扫码。

同一个扫码页服务三种目的，靠**入口带目的参数**区分，不建三个扫码页：

| 目的 | 从哪进 | 扫到后去哪 |
|---|---|---|
| 到场打卡 | 主页扫一扫 → 点位码/NFC | `03 巡检打卡`（表单页），凭证条显示"已核验" |
| 工单核验 | `10 工单整改` 顶部「扫码核验」/ `12 维保执行` 单台核验 / `13 工单详情` | 回到来源页并解除单台核验锁定 |
| 设备查询 | 主页扫一扫 → 设备码 | `35 设备详情` |

扫码页结构（全屏，无底栏）：

```
← 关闭        扫一扫            [相册]
┌───────────────┐
│   取景框 + 扫描线   │
└───────────────┘
当前目的：打卡 · 1栋1楼大厅消防栓（已识别点位，等待扫码）
[手电筒]   [输入编码]   [NFC 贴近]
```

- 识别成功 → 直接跳目的页，不停留、不弹"识别成功"。
- 识别失败分因：非本点位码 / 围栏不符 / 定位失败 / NFC 未识别 / 码已作废 → 就地显示原因 + 「重扫」+「输入编码」+「联系管理员」，见 `63 扫码与核验失败`。**不提供"免核验继续"**。
- 连续扫（资料预登记 `39`）在扫码页内计数，右上角显示"已扫 N 份"，可随时退出进入核对。

## 3. 层级与返回

**系统返回键与页面 `←` 同一逻辑**（不拦、不改语义）：只在 L4 表单已填时拦一次（保留草稿/放弃/继续填写）；弹层打开时返回**只关弹层**，不退页面；禁止"再按一次退出"这类双段退出。

| 层 | 形态 | 返回方式 |
|---|---|---|
| L1 | 五 Tab 根页 | 无返回；重复点 Tab 回根并滚顶 |
| L2 | 业务列表/入口页（如 `02 我的任务`、`14 设备台账`） | 导航栏 ← 回上屏 |
| L3 | 详情页（如 `13`、`26`、`27`、`28`） | ← 回列表，**保持列表滚动位置与筛选** |
| L4 | 表单/录入页（`03`、`10`、`21`、`37`） | ← 且表单已填时弹"放弃本次填写？"（保留草稿/放弃/继续填写） |
| 半屏 | 登记、筛选、确认弹窗、驳回原因 | 下滑或「取消」关闭；遮罩不可点关闭 |
| 全屏遮罩 | 签字、图片查看、扫码 | 显式「关闭」或系统返回 |

- 导航栏：左 ← 或 ✕，中间标题 ≤10 字（超长用页面内标题承载，导航栏写通用名如"记录详情"），右侧**最多一个**图标（`⋯` / 搜索 / 筛选三选一）。
- 提交成功 → 跳**记录详情**（不是回列表）；从详情 ← 时列表已刷新并定位到该条。
- 深链/通知直达失效 → `67 通知直达失效`，不进空白页。

## 5. 角色定义（本轮只这四个）

| 角色 | 典型身份 | 主战场页面 |
|---|---|---|
| **巡检员** | 一线巡查、打卡、整改执行 | 02、03、10、12、19、27、61/62 |
| **主管 / 项目经理** | 审核、派单、复查、签署、看板 | 18、26、31、11、13、16~17、20、45、47、48 |
| **维保工** | 换粉/水压试验执行、维保登记 | 02、12、21、28、33/34 |
| **租户管理员** | 跨小区范围、配置与兜底 | 15、45~53、全部只读 |

- 岗位/角色在后台配（`14-权限与岗位模型.md`）；App 只表达"我能看什么、能做什么"。
- 一人一角色；需要第二个身份时另建账号（不设切换身份）。
- 审批资格 = 是否当前节点候选人；**能审必能看**，所以审核人在详情页看到的内容与执行人一致（`01 原则 2`）。
