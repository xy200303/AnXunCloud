# 04 逐页交互清单（69 页）

固定读法：**看到什么 → 点哪里 → 发生什么**。每页六段，缺一段即未定稿。

- **现状**：`已建（画板名）` / `待建` / `空号`。画板名与 Penpot 逐字一致。
- **角色**：巡检员 / 主管（含项目经理）/ 维保工 / 租户管理员；`—` 表示无入口。
- 编号沿用 `docs/品管家/原型图/penpot/页面清单.md`：`05` 为空号，共 69 个真实界面。
- 通用规则（弹窗、批量、撤销、三态、深链、离线）只在 `05-全局交互约定.md` 定义，本清单只写"用哪条"。

## 01 主页

`P0` · 已建（画板 `01 主页`）· 角色：全部

- **入口**：登录成功后默认 Tab；任意页面提交成功后不跳主页，只更新角标。
- **首屏**：顶栏（定位图标 + 项目名 + 下拉；右侧「扫一扫」+「消息」带未读角标）→ 浅蓝滚动通知条（喇叭 + 公告 + 右侧公告文字）→ 2×2 指标卡（报事报修件数/完结率、物业收费/维保率，标统计周期）→ 最近使用（我的任务、巡检督查、抢单池、设备台账）→ 智管（巡检督查、工单管理、承接查验、品质报告、岗勤管理）→ 智控（设备台账）。
- **点哪 → 去哪**：项目名 → 半屏项目下拉（切换后不重新登录，列表与看板按新范围重取）；通知条左侧「通知公告」→ `06`；右侧公告文字 → `50`；指标卡 → `48`；最近使用/分组格 → 对应页面；分组右上「更多 ›」→ `49`。
- **弹窗**：项目下拉 = 半屏 sheet（列出"我的全部项目"+"管辖 N 个"）；切换后回主页顶部并轻提示"已切换到 戎安华府"。
- **空态/失败**：指标卡失败 → 卡内「重试」，**不显示假零**；无待办 → 不显示角标（角标只挂"待我处理"的入口，口径=待办条数）；某分组全部无权限 → 该分组整块不出现。
- **角色**：全角色可见；宫格按权限过滤。巡检员看不到打卡审核/派单管理/报告中心；租户管理员看全部但执行类入口为只读。

## 02 我的任务

`P0` · 已建（画板 `02 我的任务`）· 角色：巡检员、维保工、主管

- **入口**：主页「最近使用·我的任务」；`06 通知` 的待办通知；首页角标。
- **首屏**：筛选 tabs（全部 / 巡检 / 工单 / 维保）→ 逾期统计一行（`2 项已逾期`）→ 任务卡列表：类型 pill + 对象名 + 位置 + 期限 + 状态 pill + 一句事实（如"已整改 1/2 项"）。
- **点哪 → 去哪**：**整卡 → 按类型进** 巡检 `03`、整改 `10`、维保执行 `12`、工单 `13`；被驳回卡 → `28`（驳回重提）；卡内唯一快捷动作 = 主操作提示（去巡检 / 去整改 / 到场登记 / 去修改），点它和点整卡同效。
- **弹窗**：无。**本页不加多选**——四类任务动作各不相同，批量无意义（审计第 7 条结论）。
- **空态/失败**：空态「今天没有任务」+「去工单池看看」（有抢单资格时出现）；失败 → `66`；加载首屏骨架（`65`）；长列表底部「已显示 7/12 项 · 加载更多」。
- **角色**：只显示派给本人的任务；**自己抢来的单不在此列**（抢单在 `04`，单在 `13` 里执行）；主管看自己名下任务，审批在 `18`。

## 03 巡检打卡（表单页）

`P0` · 已建（画板 `03 巡检打卡`）· 角色：巡检员

- **入口**：`02 我的任务`→巡检卡「去巡检」；主页扫一扫 → 点位码/NFC 命中后直接进本页。
- **首屏**：凭证状态条（已核验绿 / 未核验红且表单只读）→ 进度行（`已完成 4/6`、右侧 `异常 1 项待审`）→ 检查项卡若干 → 底部固定「提交本点位」。每张卡顺序固定：标题 + 必拍 pill → 标准（13 灰）→ 照片组 + 拍照位 → `正常 / 有异常` 分段（等宽 ≥48）→ AI 一行 → 异常时才展开观察点 chips + 备注。
- **点哪 → 去哪**：拍照 → 上传并**当场异步识别**（不阻塞继续填别的卡）；点「正常/有异常」→ 选中并留改判痕迹；点「有异常」→ 卡内展开观察点与备注；进度行右侧 → 跳到第一个未完成项；导航栏 `?` → `29` 无法检查面板；个别标签不可读 → 该卡内局部「无法检查」；设备项「看档案」→ `35`；`←` → 若已填内容弹「保留草稿 / 放弃 / 继续填写」。
- **弹窗**：无提交确认弹窗（提交是当页主操作）；提交成功 → 跳 `27 巡检记录详情`。
- **空态/失败**：AI `pending/running` → 提交置灰 + 按钮上方「还有 N 项正在识别」；AI `error` → 该卡「重试 / 人工核查」→ `30`；凭证未核验 → 顶部红条 + 表单只读 +「去核验」；`blocked_by_config` → 整页替换为「该点位配置有误，已通知管理员」，**无自助解除、不能用无法检查顶替**；断网 → 本地草稿 + 底部「已存本地 · 待上传」，恢复后自动续传（`62`）。
- **角色**：仅任务执行人；改派后原执行人只读。
