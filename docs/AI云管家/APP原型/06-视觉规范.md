取值来源：`.tmp/ds/ds2.js`（设计系统 v2，Penpot 原生自动布局）+ 对比度实测（本文 §1.1）。**改设计系统会连带影响全部已建画板**，所以本表是只读契约：新增页面取值照抄，不新增硬编码色与碎值。

> 本轮（2026-10-25）依据 `09 E2`（WCAG 1.4.3 / 1.4.11）与 `教训 8` 补了三类东西，都标在对应小节：① 每个色值的**实测对比度**与允许用途；② **新 token**（`ink3d`、`okInk`/`warnInk`/`dangerInk`、`stroke`）；③ **48 热区 / 选择列 48 / 正文 15 / 危险按钮 ≥24** 的落地数值。

### 1.1 对比度实测（WCAG 2.2：正文 ≥4.5:1，大字/图形/边框 ≥3:1）

| 前景 / 背景 | 对比度 | 判定 | 结论 |
|---|---|---|---|
| `ink` #1D2129 / 白 | 16.1:1 | ✓ 正文 | 标题、正文默认 |
| `ink2` #4E5969 / 白 | 7.1:1 | ✓ 正文 | 次级正文；灰底上也够（6.6:1） |
| `ink3d` #6B7385 / 白 | **4.7:1** | ✓ 正文 | **12~15 号说明文字的新默认值** |
| `ink3d` #6B7385 / `bg` #F5F6F8 | 4.3:1 | ✗ 正文 | 灰底容器上的说明改用 `ink2` |
| `ink3` #86909C / 白 | **3.2:1** | ✗ 正文 / ✓ 图形 | **不再做正文**；可做图标、≥18 号大字、水印 |
| `ink3` #86909C / `bg` #F5F6F8 | 3.0:1 | 临界 | 灰底上的图标边界改用 `stroke` |
| `ink4` #C9CDD4 / 白 | 1.6:1 | ✗ | 只做装饰；做文字或控件边界即违规 |
| `stroke` #7A8290 / 白 | 3.9:1 | ✓ 图形 | 输入框、未选勾选框、分段按钮未选态 |
| `stroke` #7A8290 / `bg` | 3.6:1 | ✓ 图形 | 灰底上的控件边界 |
| `brand` #2B5AED / 白 | 5.5:1 | ✓ 正文 | 链接、主按钮文字（白字/蓝底同值） |
| `brand` #2B5AED / `brandBg` #EAF0FE | 4.9:1 | ✓ 正文 | 品牌 pill 文字 |
| `ok` #2BA471 / `okBg` #E7F6EF | **2.8:1** | ✗ 正文 | pill 文字改用 `okInk`（4.8:1） |
| `warn` #ED7B2F / `warnBg` #FFF3E8 | **2.6:1** | ✗ 正文 | pill 文字改用 `warnInk`（4.6:1） |
| `danger` #F53F3F / `dangerBg` #FFECE8 | **3.2:1** | ✗ 正文 / ✓ 图形 | pill 文字改用 `dangerInk`（5.1:1） |
| 白字 / `danger` #F53F3F 实底 | 3.2:1 | ✗ 正文 | 危险实底按钮**不用白字**，走 `dangerBg` + `dangerInk` 组合 |

规则：

- **颜色不承担"能不能点"**：禁用态用灰底 + 弱字，不用降低主色透明度糊成一片；红色只给状态与危险动作。
- 一屏内不出现两个不同色的"主按钮"；主色 `#2B5AED` 每屏最多一处填充块。
- **状态 pill 一律"浅底 + 深字"**：底用 `okBg`/`warnBg`/`dangerBg`/`brandBg`/`grayBg`，字用对应的 `okInk`/`warnInk`/`dangerInk`/`brand`/`ink2`。用 `ok`/`warn`/`danger` 当 12 号文字色（2.6~3.2:1）即违规。
- 可交互控件的边界（输入框、勾选框、分段按钮未选态）用 `stroke`，**不得**用 `line2`/`ink4`（1.6:1，等于没有边界）。
- 禁 emoji 当图标；禁页面内新增未登记颜色（含渐变）。

> 来源：`09 E2`、`09 §七.10`、`教训 8`、`08 #3`（颜色过度承担语义）

## 2. 字号（八档，唯一标准）

| 字号 | 用途 | 常见位置 | 能否作正文 |
|---|---|---|---|
| 26 | 大数字 | 指标卡数值、首页看板 | 否（数字专用） |
| 22 | 页内大标题 | 登录页应用名、空态标题 | 否 |
| 17 | 页面标题 / 对象名 | 导航栏标题、详情页对象名 | 是（标题） |
| 16 | 卡片标题 / 分段按钮 | 检查项标题、`正常/有异常` | 是（标题） |
| 15 | 列表标题 / **正文默认** | 卡片标题、按钮文字、行标题、备注、说明 | 是（正文下限） |
| 14 | 辅助正文 | **只给**时间戳、单号、计量单位 | 否 |
| 13 | 次要 | 标准原文、kv 值、pill 内次要字 | 否 |
| 12 | 辅助 | pill、卡内小注 | 否 |
| 11 | **仅底栏文字** | `tabbar()` 内，不用于其他任何地方 | 否 |
| 10 | **仅两处**：宫格/胶囊数字角标、照片水印条小字 | 不用于正文、标题、说明、按钮 | 否 |

- 字体 `Noto Sans SC`；字重只用 400 / 500 / 600 / 700。
- **正文档位 15**：备注、说明、提示句从 14 提到 15；14 只剩"时间戳 / 单号 / 单位"三个用途（`09 §七.7`）。
- **大字模式**（`07 我的 → 设置`）：正文 15→17、次要 13→15、行高 +2；不新增档位，不靠系统字号透传（H5/Android 不一定透传）。
- **不采用** `02-App框架与UI布局.md §7` 的 13/14/16/18 四档，也不使用 18 这一档（`01 原则 9` 已定）。旧页面里出现 18 的按 17 或 22 归位。
- 同一层级的字号必须一致：卡片标题 15/16 二选一后全站统一（当前列表卡=15、检查项卡=16）。

## 3. 间距与几何

| 项 | 值 | 说明 |
|---|---|---|
| 画板宽 | 390 | 内容可用宽 **358**（左右 16） |
| 卡片宽 | 358 | — |
| 卡内边距 | 12 / 16（列表卡）、14 / 16（详情、表单卡） | **水平内边距统一 16**，不再用 12/14 |
| 卡内容宽 | **326** | 358 − 16×2（旧文档写 330，按本条校准） |
| **右边线** | **x = 卡左 + 342** | 时间 / 单号 / 状态 pill / 数值全部贴这条线 |
| **选择列** | 宽 **48**（视觉 22×22 居中） | 与标题首行同高 |
| 选择列与文字间距 | 10 | 文字宽 = 326 − 48 − 10 = **268**，右边线不动 |
| 卡片间距 | 12 | 卡与卡之间不画分割线，靠留白 |
| 卡内元素间距 | 10 | 标题层与媒体层之间 10；紧凑列表用 8 |
| 区块标题与内容 | 8 | — |
| 并排按钮 gap | 12 | 定宽 84 / 96 / 108 |
| **危险按钮与「取消」** | **gap ≥ 24** 且宽度不同 | 弹窗内「取消 108 + 动作 238」= 358，正好满宽 |
| 图标与文字 gap | 8~10 | — |
| 底部固定栏内边距 | 12 / 16 / 16 / 16 | 带阻断原因行时上方加 8 |
| 节奏 | 4 / 8 的倍数 | 不出现 3、5、7、9 这类碎值 |

- **48 热区**：所有可点元素的实际热区 ≥48×48（视觉可 22~23），靠透明 padding 补足，不靠相邻重叠；相邻可点目标间距 ≥12。
- 改选择列宽必须**同批**改文字宽与右边线，不允许只改一个（会破"一条右边线"）。

## 5. 图标

- 24 网格线性，`stroke-width 1.8`，圆头圆角连接；颜色随语义（`ink` 主 / `ink3d` 次 / 语义色）。
- 统一进 **22×24 固定槽**（宽 22、高 24），图形 16~18 居中；短文本不设固定宽。
- 常用图标取自 `ds2.js` 的 `ICON`（back/chev/down/close/search/bell/pin/cal/clock/check/alert/info/camera/plus/mic/send/doc/shield/wrench/box/list/user/users/cog/more/filter/qr/refresh/edit/upload/print/star/grid/home/archive/chat/play/download/sparkle/lock/phone/flag/eye/swap）。
- **同一屏内图标不重复**：靠图标分不清功能时，图标就是占地方，改用文字或去掉。
- 图标必须有可访问名称（`aria-label` / 文案伴随），不单独用图标表达状态。
- 照片水印：时间 + 姓名 + 地点压在半透明深色条（`#101A2C` / 62%）上，字号 10（这是 10 号的两个合法用途之一）。

## 6. 按钮

| 类型 | 底 / 字 | 用途 | 默认高 |
|---|---|---|---|
| primary | `#2B5AED` / 白 | 每屏唯一主操作 | 46（大按钮 52） |
| ghost | 白 / `#2B5AED` + `stroke` 描边 | 次要并列动作 | 46 |
| gray | `#F2F3F5` / `ink2` | 禁用、次要 | 46 |
| danger | `dangerBg` #FFECE8 / `dangerInk` #C02A2A + `danger` 描边 | 驳回、删除、作废 | 46~52 |
| ok | `#E7F6EF` / `okInk` | 批量通过等正向批量 | 48 |

规则：

- 高度：常规 46；**触区 ≥48**（可点区不足时用透明 padding 补足，不改视觉高度）；底部主操作 52。
- 并排按钮**定宽 + 固定 gap**，不按剩余宽度拉伸：取消 108 + 主操作 238（弹窗内），卡内 84/96，底栏 96/108。
- **危险动作与「取消」拉开 ≥24**（颜色 + 间距共同表达危险），且危险按钮**不默认聚焦、不上主色、不被回车默认触发**。
- 阻塞时按钮置灰并**保留原文案**（"提交本点位"），缺什么写在按钮上方。
- 按钮文案写**结果与去向**（「通过 5 条」「驳回并通知」「提交，待主管确认」）；禁止「确定 / 是 / OK / 提交」单字按钮。
- 同屏最多一个 primary；卡片内的轻量快动作（「通过」）用 ghost，不用 primary。
- 按钮进行态**换文案**（"提交本点位"→"提交中…"）并禁用；<300ms 不显示 loading，300ms~1s 出骨架或按钮内转圈，>1s 给"正在做什么 + 可取消"。

## 8. 版面硬规则

1. 卡片四层骨架：标题层 → 媒体/关键字段层 → 主操作层 → 条件详情层（只在对应状态展开）。
2. 右侧贴边：时间 / 单号 / 状态 pill / 数值一律贴**同一条右边线**（卡左 + 342），跨卡对齐。
3. 一信息只出现一次；顶部统计行、底部操作条各出现一次，不重复统计与 AI 提示。
4. UI 不写配置说明、不写规则解释、不写"点击查看"这类废话。
5. 长文本用定宽 + 显式给高（Penpot 不会自动重排折行文字的高度，直接用 `txt(w)` 会压掉下一行）。
画板高度跟随内容（自由高度）；仅在需要模拟真机首屏时临时裁切，不作为设计约束。
7. **字号只从八档取**，正文 15；14 仅时间戳/单号/单位；11 仅底栏；10 仅角标与水印。
8. **颜色只从 §1 表取**，状态 pill 用深字；`ink4` 不做文字与控件边界。
9. **48 热区**：视觉可以小，热区不能小；并排按钮定宽 + gap 12，危险动作与取消 gap ≥24。
