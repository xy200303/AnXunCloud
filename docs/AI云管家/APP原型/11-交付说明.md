## 画布结构

- **y=0**：01 登录 / 02 AI助手 / 03 主页 / 04 卷宗库 / 05 社区 / 06 我的
- **y=1200**：二级页与弹窗（工单、巡检、审核、复查、台账、承接、报告、通知、岗勤、维保、扫码、状态页、账号与签名等）
- **y=2600**：空态 / 加载态 / 失败态
- **y=5000**：旧版参考板（统一「旧·」前缀，不参与评审）

## 如何给甲方演示

1. Penpot 打开文件 → 右上角 Share → 权限设为「Anyone with the link can view」
2. 复制链接发给甲方（无需注册）
3. 进入后从 flow 列表选「03 主页」或「01 登录」开始点
4. 可点击链路：底栏五 Tab 互跳、登录→主页、我的→云管家→关于云管家、主页→智管·更多→管理功能
5. 长页面在演示模式里可上下滚动（画板高度＝内容高度）

## 已验证 / 已知

- 48 块画板逐屏导出，无空白板（最小 30 KB 以上）
- 未接线的入口：工单池卡片→工单详情、巡检记录→记录详情、通知→通知详情、承接查验→清单等，属于"下一步接线"范围
- `03a 管理功能` 的九宫格因自动高度算不出，人工锁定 829 高
- Penpot 导出服务偶发超时，重试可恢复

## 工程约束（后续接手必读）

1. 画板高度＝内容高度，无 844 下限
2. 不追加覆盖图元；交互只挂在已有元素上
3. 弹窗分型：选项＝底部上滑 sheet，确认＝居中弹窗；遮罩用画板填充
4. 居中卡片用 padding 顶位，不用 justify:center
5. 长句按语义拆行
6. 一次只建一屏，页间 sleep 20s
