## 施工硬规则（摘自 01，务必遵守）

1. 一个对象只有一个详情页；巡检员/主管/已审共用骨架，主管只多两个按钮
2. 列表＝多选卡片 + 常驻置灰批量条 + 退出多选两条路径 + 整卡进详情；AI 只代勾不代提交
3. 审核/确认：主操作用实心主色，次操作（驳回）用文字+图标，gap ≥24，两者都进阻断弹窗；驳回原因必填
4. 单件工单要核验，整批/打包不打卡只逐台实拍；不允许分批提交；审核链通过即自动入池
5. UI 不写规则说明（不出现"GPS 已关""不能用相册"这类）
6. 正文 15、次要灰 `#6B7385`（≥4.5:1）、可点区 ≥48、图标 22×24 槽、一条右边线
7. 空态三分：无数据 / 筛选无结果（给清空）/ 无权限
8. 不画没有依据的功能；扫一扫常驻主页顶栏，三处复用同一扫码页

## 画板绘制约定

- 宽 **390**，零绝对坐标，全部用 ds2 的 flex 组件
- 高度 **max(内容高, 844)**：不足一屏补到 844；超过一屏画布变长，并在 844 处加「首屏到此 · 以下需滚动」浅橙横条
- 生成脚本：`.tmp/ds/*.js` + `.tmp/ds/run.py`（Penpot 插件内执行）
- 校验：`.tmp/ds/check_svg.py`（导出 SVG 里 `<text>` 数 > 0 才算字形没丢）、`render_raw.py` 出图后必看
- Penpot 插件易被浏览器挂起：**一次只建一屏**，屏间 sleep 20~30s；报 `frozen/suspended` 就等人到 Penpot 标签页点一下，不要连续重试
- 2026-10-26 凌晨实测：挂起后远程手段（重试 / 激活窗口 / 切标签）都无法唤醒，只能人工点 Penpot 标签页
