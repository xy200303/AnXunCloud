## 104 租户管理

## 108 发布管理

`已出图（108-发布管理.png）` · `P2` · 角色：超级管理员

- **进**：侧栏 `平台管理 → 发布管理`。
- **看到**：列 `平台 / 版本 / 文件名 / 大小 / 备注 / 上传时间 / 操作`；平台取值 `Android / HarmonyOS / iOS / 小程序码`；行内动作 `下载` / `删除`（小程序码为 `查看`/`删除`）。页面一行说明：**每个平台只生效最新上传的一条**（官网下载页展示它，App 启动检查更新也对齐它，强制更新不可跳过）。
- **点哪**：`＋上传发布物` → 弹窗（`*平台` / `*版本号` 如 `1.0.0` / 备注（如更新内容说明）/ **更新方式：弱更新（可"以后再说"）· 强制更新（不可跳过）** / `*文件`（拖拽或点选，Android 仅 `.apk`、单文件 ≤200 MB））→ `开始上传`。
- **抽屉/弹窗**：上传弹窗单层；版本号与 App `manifest.json` 的版本比较给提示（"低于当前推送阈值，将不触发更新"）。
- **发生什么**：**不设"设为当前"**——按平台取最新一条即生效；App 强更阈值与后台发布联动；**本页当前无分页**（`13 §12` 已登记缺陷，需补）；权限点与"站点设置"共用一组 `system:site:*`，**拆权限点未完成前不要新增更多动作**。
- **空态/失败**：无发布物 → 空态 + 上传；上传失败 → 断点提示 + 重试；文件类型/大小不符 → 就地拒绝并说明允许类型与上限。
- **角色**：仅超管；发布属高危，写审计。
