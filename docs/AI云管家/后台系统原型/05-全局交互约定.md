# 05 全局交互约定

跨页一致的行为只在这里定义一次。逐页清单（`04`）只写"用哪条"，不重复解释。

## 1. 筛选与分页

- **筛选区形态**：`el-form :inline="true"`，每项 `label` + 控件，默认最多 6 项，多的收进「更多筛选」折叠区；`查询` 为主按钮，`重置` 为文字按钮，二者固定在最右。
- **触发时机**：下拉/日期选完即查询；文本框按 `Enter` 或点查询才生效（不做输入即搜，避免打库）。
- **保留与记忆**：切换分页/排序不重置筛选；**筛选条件与分页大小按"用户 + 页面"存本地**，下次进来恢复（`13 §9.5`），但**不跨用户、不影响数据范围**。
- **分页**：默认 20，可选 **10 / 50 / 100**；**上限 100 是服务端口径**（`09 §5.2`）；超过 1000 行的可视列表走虚拟滚动。跨页全选必须明确范围（见 §3）。
- **加载**：首屏出表头 + 骨架行，筛选区立即可用；切页/切筛选只给表格区淡遮罩，**不整页 spinner、不丢滚动位置**（`13 §9.1`）。
- **排序**：只对可索引字段开放（时间、状态、完成率）；点列头三态循环（无 → 升 → 降）。
- **URL 同步**：关键筛选（小区、期间、状态、Tab）写进 query，便于分享与标签页恢复；深链规则见 `02 §7`。

## 2. 表格

- 行高 **48**，表头 48，斑马纹可选；单元格内不放多行说明（次要信息用 12px 副行，最多两行）。
- 列宽：对象标识列给足（≥180），状态列定宽（96），时间列定宽（140），操作列定宽（按动作数 120~200）并**固定在右侧**。
- 状态一律用 `el-tag`（语义色见 `06 §2`）+ 文字，**不单靠颜色**；数量角标 `el-badge`。
- 超长文本用 `show-overflow-tooltip`，不在单元格里换行三段。
- 行内动作 ≤3 个直出，其余进「⋯」；**危险动作在下拉最末**且 `type="danger"`。
- 空态放表格位置（`el-empty`），筛选区与工具栏保留。

## 3. 批量选择

- 三件套：**表头全选 + 单行勾选 + 条件批量**（如"按楼栋批量打包"）。
- **全选 = 当前筛选结果全选**，点表头选择框先确认："将选中 24 条（当前筛选结果，不是本页 20 条）"。部分选中 → `indeterminate` 半选。
- **筛选/Tab/分页大小变化 → 清空已选**，并给一行"筛选已变，选择已清空"（不静默保留）。
- 选择数只在工具栏出现**一次**（`已选 3 项` + 一句可行性提示，如"同小区同专业，可合并为一单"）。
- 跨小区/跨专业/跨模板的批量 → **阻断并提示拆分**，不静默合并；行本身置灰不可选。
- 批量动作**一次确认**（写清对象 + 条数 + 后果 + 可否撤销），执行后给 `已处理 / 成功 / 失败 / 跳过` 四个数 + 失败明细 + 导出 + **仅重试失败**；已成功项不重做。
- 逐项判断类（如工单审核）**不提供批量通过**——批量会掩盖证据差异，属有意例外，需在页面上写清理由。

## 4. 抽屉与表单

- 宽度三档：**480**（单列表单）/ **620**（详情、带表格的配置）/ **760**（左右对照、长表格）。超过 760 说明该做整页。
- 结构：标题（对象名）+ 右上 `⋯`/`×` → 内容区块（区块标题 16 + 分隔线）→ 底部操作区（右对齐，主操作在最右）。
- **抽屉内不叠弹窗**：需要理由/确认时用抽屉内联输入 + 底部确认条，或用 `el-popconfirm`；确需单独弹窗时先关抽屉再开弹窗（不叠层）。
- 遮罩**要淡**（`rgba(0,0,0,.3)`）——抽屉的价值是保留上下文；点遮罩可关闭**只限查看类**抽屉，编辑类抽屉点遮罩先问"放弃修改？"。
- 关闭后回到原行、原筛选、原页码、原滚动位置；保存成功后列表**高亮该行**并刷一次数据。
- 校验：提交时统一校验，字段级红字 + 滚动到第一个错误；`Enter` 提交、`Esc` 取消（有改动时先确认）。
- 保存中按钮 `loading` + 禁用，前后端共同防重；失败**保留已填内容**并把错误定位到字段（`13 §9.4`）。

## 5. 二次确认与危险操作

| 类型 | 形式 | 必写内容 |
|---|---|---|
| 一般确认（发布、生成、提醒） | `ElMessageBox.confirm` | 对象 + 条数 + 一句后果 |
| 危险确认（停用、删除、作废、撤销 token、批量驳回） | 自定义 `el-dialog`（可带原因输入） | 对谁 / 会怎样 / **能否撤销**；危险按钮 `type="danger"`、**按钮文案写结果**（`驳回并通知`），与「取消」不同宽、**间隔 24**、不默认聚焦 |
| 破坏性且不可逆（归档、重出、强更发布） | 输入确认（键入对象名或"确认作废"） | 明确"不可撤销"，不给撤销入口 |

- **不做乐观更新**的：审核、签字、归档、确认类、权限变更（等服务端回执 + `revision` 条件更新，防重复审核覆盖新修订）。
- 可乐观更新的：行内启停、排序、置顶（失败回滚 + 提示）。
- 有业务数据的对象**不提供删除**，只提供停用并提示影响（`13 §9.4`）。
- **撤销两分法**（`01 §6`、与 App 同口径）：会产生下游事实的动作（通过/驳回/签字/归档/批量/维保确认）**只弹确认框、不给撤销**；纯本地动作（清筛选、取消选择、删草稿）**不弹框、给 5s 撤销 toast**。两者**不许叠加**。

## 6. 导入与导出

- **导入**三步：`下载模板` → `上传 Excel 文件` → **预览与错误行**（逐行 ✓ / 具体错误）→ 确认导入。**冲突不静默覆盖**，覆盖类操作要显式勾选"覆盖同 code 项"。
- 导入是长任务：四分进度、可下载错误报告、**仅重试失败行**；大文件（>1 万行）拒绝并提示分批。
- **导出**统一格式：当前筛选结果（不是本页）、列与表头一致、文件名带日期与范围（`设备台账_戎安华府_20261024.xlsx`）；超 5 万行走异步任务 + 站内通知下载。
- 涉及证据/归档的下载（报告 PDF、原始照片、日志、台账）**必须记审计**（谁、何时、下了哪几份、走什么授权），`report:download` 不能绕过租户与数据范围。
- 导入导出按钮都要 `v-perms` 控制；无权限**不渲染**，不留禁用按钮。

## 7. 权限校验与提示

- **无权限 = 入口不出现**（菜单不渲染、按钮不渲染、Tab 不渲染）。看得见点不动的按钮一律不画。
- 深链进入无权限页 → 独立 **403 态**：一句"你没有查看该范围的权限" + 指向谁能开（岗位/管理员）+ 返回工作台。**不显示数据轮廓、不混进空态**。
- 数据范围为空（项目级岗位无任职行）→ 列表给"你的岗位未设置任职小区，因此没有数据范围"+ 指向管理员；**fail closed**，不显示空表当"没有数据"。
- 操作被服务端拒绝（403/409）→ 行内提示 + 收起按钮，并说明"当前环节已变更/已被他人处理"，不整页报错。
- 平台操作（超管）**必须显式指定目标租户**：没有指定时给"请先在顶栏选择目标租户"，不隐式落到默认租户。
- 审批资格**不是权限点**：能否审某条 = 是否为该条当前节点候选人；候选人身份即给该条读权限（`14 §1.5.3`）。因此不设"审核/签字"权限点，权限树里也不出现这类叶子。

## 8. 长任务与状态

- 报告生成、批量导入、二维码生成、批量确认统一走 River：**持久状态 pending / running / done / failed**，刷新不丢，离开页面停止轮询（用户在场 2s 轮询或 SSE，后台批处理 5~10s）。
- 进度按 **已处理 / 成功 / 失败 / 跳过** 四分显示；不把"处理完成"写成"全部成功"。
- 可取消的任务，取消是**显式状态**（不是静默丢弃）；不可取消的（已进渲染）明确写"已进入渲染，不可取消"。
- 队列积压与最老任务年龄在运营看板/平台管理可见。

## 9. 四类空态 + 失败

| 态 | 文案要点 | 下一步 |
|---|---|---|
| 无数据 | "还没有 X" | 给创建入口（有权限时） |
| 筛选无结果 | "该条件下没有匹配的 X" | 给「清空筛选」，**不说"还没有数据"** |
| 无权限 | "没有查看 X 的权限" | 指向谁能开，不显示数据轮廓 |
| 配置缺陷 | 具体缺什么（缺坐标/围栏非法/断链/未配签署/未配模型） | 直达修复页 + 已通知谁 |
| 请求失败 | 发生了什么 + 重试 | **行内/卡内重试**，不整页报错；表单失败保留已填内容 |

- **四类不许共用一句"暂无数据"**：四类背后是四种下一步（去创建 / 清筛选 / 找管理员 / 去修配置），混用等于让人无路可走。
- 加载失败**不显示假零**、不伪造上次数据；空与 0 分开（"0 条"是有数据的结果，"还没有"是没配）。
- 阻断原因分行列在按钮上方并可点到具体对象，**按钮文案只说动作**（"发布"置灰，上方写"还差 2 个签字位未绑定"）。

## 10. 时间、数字与文案

- 时间：当天 `HH:mm`，本年内 `MM-DD HH:mm`，跨年 `YYYY-MM-DD`；列表时间列右对齐，相对时间（"3 天前"）只在 `<el-tooltip>` 里给。
- 期间统一"月"（`2026-09`），显示为 `2026年9月`；账期与归档按期间对齐。
- 数值右对齐、带单位、单位随列头写一次；越界数值给"越界"文字 + 危险色（不只靠颜色）。
- 计数单位固定：`条 / 项 / 台 / 册 / 单 / 份 / 人`，同一对象不混用两种说法。
- 文案：不写配置说明、不写规则解释、不写"点击查看"；错误只说"发生了什么 + 下一步"，不写制度说明、不写威胁语（"操作将被审计"不进 UI）。
- 报告类**只写册数不写册号**，册号位显示「册号待定」；承接查验按类别名，不硬编码 1~6。

## 11. 标签条、草稿与离开

- 打开页面即加标签；`工作台` 固定不可关；标签标题可被业务名替换（"字典数据-通用状态"）。
- 关闭有未保存改动的标签 → 拦截三选一（保存草稿 / 放弃 / 继续编辑）。
- 整页编辑器（`41 / 43 / 53 / 59 / 84 / 84b`）支持**服务端草稿**：`保存草稿` 明确可见，草稿态在列表里用 `草稿` 标；抽屉/弹窗不做服务端草稿（关闭即丢，但关闭前提示）。
- 浏览器刷新不丢标签与筛选（本地记忆），但**不承诺跨设备恢复**。

## 12. 键盘与可达性

- `Ctrl/Cmd + K` 全局搜索（菜单 + 对象跳转）；`/` 聚焦当前页关键字；`Esc` 关抽屉/弹窗（有改动先确认）；`Enter` 提交表单。
- 表格支持键盘上下移动行、（有权限时）`Space` 勾选；抽屉打开后焦点进第一个可编辑项，关闭后回触发按钮。
- 图标按钮必须有 `aria-label` 或 tooltip 文案；状态不能只靠颜色，必须带文字。
- 尊重系统减弱动效设置；动画只用 `transform/opacity`，150~300ms。
