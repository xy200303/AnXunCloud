# 06 视觉规范

取值来源：`frontend/src/styles/variables.scss` + `element-vars.scss`（Element Plus 变量表）+ `index.scss`（表格与工具条）。**这些是只读契约**：新页面照抄 token，不在组件里写裸色值、不新增碎值。
目标视口 **1440×900**（渲染器出 1280×800 静态图，等比同一套尺寸）；小于 1200 内容区给横向滚动，不压缩列宽。

## 1. 颜色

| 语义 | Token | 值 | 用在哪 |
|---|---|---|---|
| 品牌主色 | `$color-primary` | `#2B5AED` | 主按钮、选中行、链接、Tab 激活条 |
| 主色 hover / active | `$color-primary-hover` / `-active` | `#4A74F0` / `#1F47C8` | 交互态 |
| 主色浅底 | `$color-primary-light` | `#EAEFFF` | 选中行底、hover 行、图标浅底 |
| 成功 | `$color-success` | `#2BA471` | 已通过、正常、已归档 |
| 警示 | `$color-warning` | `#ED7B2F` | 待审、临期、断链、配置缺陷 |
| 危险 | `$color-danger` | `#D54941` | 删除、作废、驳回、越界 |
| 信息 | `$color-info` | `#909399` | 中性标签 |
| 页面底色 | `$color-bg-page` | `#F5F6F8` | 内容区背景 |
| 卡片 / 浮层 | `$color-bg-card` | `#FFFFFF` | 卡片、抽屉、弹窗 |
| 侧栏 | `$color-sidebar` | `#1F2D3D` | 侧栏底；子菜单 `#1A2634`，hover `#26374B` |
| 侧栏文字 | `$color-sidebar-text` | `#BFCBD9` | 未选中项；选中项白字 + 主色左条 |
| 表头底 | `$color-table-header` | `#FAFBFC` | `th` 背景 |
| 文字·主 | `$color-text-primary` | `#1F2329` | 标题、对象名、正文重点 |
| 文字·常规 | `$color-text-regular` | `#4E5969` | 表格正文、按钮次字 |
| 文字·次 | `$color-text-secondary` | `#86909C` | **只用于 16 号以上大字、图标、装饰**（白底 3.2:1，不达正文对比度） |
| 文字·次（正文可用） | `$color-ink3d`（本轮新增） | `#6B7385` | 表格内 12~13 号次要文字、说明、时间、单位（白底 **4.7:1**） |
| 文字·占位 | `$color-text-placeholder` | `#C0C4CC` | 输入占位 |
| 边框 | `$color-border` | `#E5E6EB` | 分割线、卡片描边 |
| 边框·深 | `$color-border-dark` | `#C9CDD4` | 输入框边框 |

规则：

- **主色 `#2B5AED` 每屏最多一个填充按钮**（主操作）；次要动作用默认/描边按钮，第三级用文字按钮。
- 颜色不承担"能不能点"：禁用态用 `--el-disabled-*` 灰底灰字，不降低主色透明度。
- 红色只给危险动作与失败/越界状态；警告橙只给"需要注意但没坏"（待审、临期、断链）。
- 禁 emoji 当图标；禁未登记的渐变色、彩色阴影。

## 2. 字号（五档 + 一处例外）

| 字号 | 用途 | 常见位置 |
|---|---|---|
| **20** | 页面标题 | 内容区顶部标题、抽屉标题（长标题）、弹窗标题 |
| **16** | 区块标题 / 卡片标题 | 抽屉内区块标题、卡片头、Tab 文字 |
| **14** | 正文 / 表格正文 / 表单 | 表格单元格、表单项、按钮文字、正文说明 |
| **13** | 表格次要 / 辅助正文 | 表头、单元格副行、筛选 label、时间 |
| **12** | 辅助 | 单位、来源标注、tag 内文字、小注 |
| 28（**唯一例外**） | 看板大数 | 仅 `78 运营看板` 指标卡数值（现有 `$font-size-data`） |

- 字体：`-apple-system, 'PingFang SC', 'Microsoft YaHei', 'Helvetica Neue', Arial`。
- 字重只用 400 / 500 / 600；主要按钮与标题 600，正文 400。
- 表格内**只允许 14 / 13 / 12** 三档，不出现 20/16；表头与正文同 14 时靠颜色与字重区分（表头 600 + `#4E5969`）。
- 现有 token 的映射：`$font-size-page-title` 18 → 统一按 **20**；`$font-size-card-title` 16 保留；`$font-size-body` 14 保留；`$font-size-aux` 12 保留。**不新增 18 与 15 两档**（与 App 文档的八档无关，两者不通用）。

## 3. 间距（8 的倍数）

| 项 | 值 | 说明 |
|---|---|---|
| 内容区外边距 | 24 | 页面四周；卡片之间 16 |
| 页头与首卡 | 16 | 标题下留白 |
| 卡片内边距 | 16 | 工具栏、表格外层 |
| 表单行间距 | 16（紧凑 12） | `el-form-item` margin-bottom |
| 筛选项间距 | 12 | 行内 form 的 gap |
| 按钮组 gap | 8（危险操作与「取消」之间 **24**） | 物理分开，防误点 |
| 图标与文字 | 6~8 | 按钮内、菜单内 |
| 表格单元格内边距 | 8 / 12（上下 / 左右） | 行高 48 由此得出 |
| 分页上间距 | 16 | 右对齐 |

- 只允许 **4 / 8 / 12 / 16 / 24 / 32**（4 与 12 是 8 体系的半档与半档加，**不再出现 10、14、18、22 这类值**）。
- 圆角：`$radius-small` **4**（按钮、输入、标签）、`$radius-card` **6**（卡片、抽屉内区块）、头像取半。
- 阴影：只有浮层用 `$shadow-popup`（`0 4px 16px rgba(0,0,0,.08)`），卡片静止态**无阴影**（靠 `1px #E5E6EB` 描边）。

|---|---|---|
| 目标视口 | 1440×900 | 1280 宽也能用（内容区横向滚动兜底） |

| 弹窗 | 480（确认）/ 560（生成报告）/ 720（导入预览） | 超过 720 用整页 |

## 7. 版面硬规则

1. **一屏一态**：一张原型 = 一个屏幕状态；列表与详情分开、不同 Tab 各一张、弹窗真浮在遮罩上。
2. 页头只保留标题 20 与必要的右侧主操作（唯一）；不写重复页面功能的一句话副标题，不再重复放"刷新"以外的小图标。
3. 卡片只两层：工具栏（32）+ 表格/内容；**别在卡片里再套卡片**（抽屉内的区块用标题 + 分隔线，不用嵌套卡片）。
4. 右侧对齐：状态、时间、数值、操作列右对齐或右固定，跨列可扫读。
5. 一信息只出现一次：总数只在分页出现；选中数只在工具栏出现；来源标注只在需要判断继承的地方出现。
6. UI 不写配置说明、不写规则解释、不写"点击查看"；原因与后果写进确认框或页内 alert。
7. 长文本定宽 + 省略 + tooltip，不靠换行撑高行。
8. 深色侧栏 + 白顶栏 + 灰底内容是**固定骨架**，不换主题、不加"卡片式导航"。
