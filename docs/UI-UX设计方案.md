# 物业巡检管理系统 UI/UX 设计方案

> 版本：v1.0
> 适用范围：Web 管理后台（Vue3 + Element Plus）、微信小程序巡检端（原生）
> 设计目标：**专业、克制、高效**的企业级工具产品。一线巡检员 3 分钟上手，管理后台符合物业行业用户的操作习惯，零培训成本。
> 配套文档：`docs/物业巡检管理系统方案.md`（功能与架构以该文档为准）

---

## 一、设计原则

1. **效率优先**：这是干活用的工具，不是展示品。任何装饰性元素让位于信息密度和操作效率。
2. **一致性**：同一类页面用同一套布局骨架，同一类操作用同一套交互（位置、文案、反馈），用户学会一处即学会全部。
3. **状态可见**：任务进度、打卡状态、工单流转状态，永远一眼可辨；任何异步操作都有明确的加载/成功/失败反馈。
4. **防错优于报错**：危险操作二次确认、必填项前置校验、不可用时禁用而非隐藏。
5. **克制的美学**：不用渐变大紫大蓝、不用玻璃拟态、不用 3D 插画等"AI 风/运营风"元素；对标若依（RuoYi）、阿里 Ant Design Pro 这类经过验证的企业级范式。

## 二、设计令牌（Design Tokens）

两端共用一套语义化令牌，代码中以 CSS 变量 / SCSS 变量实现，**组件内禁止写死裸色值**。

### 2.1 色彩

**品牌主色**（深青蓝，物业行业的"可靠、专业"感，同时与微信绿、告警红拉开距离）：

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--color-primary` | `#2B5AED` | 主按钮、链接、选中态、关键数据 |
| `--color-primary-hover` | `#4A74F0` | 悬停 |
| `--color-primary-active` | `#1F47C8` | 按压 |
| `--color-primary-light` | `#EAEFFF` | 选中行底色、标签底色 |

**语义色**（功能色必须同时配图标或文字，不允许只用颜色传达含义）：

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--color-success` | `#2BA471` | 已完成、正常、打卡成功 |
| `--color-warning` | `#ED7B2F` | 跳过、临近超时、待复核 |
| `--color-danger` | `#D54941` | 未打卡、逾期、异常、删除操作 |
| `--color-info` | `#909399` | 次要信息、已关闭 |

**中性色**（内容区为浅灰底 + 白卡片，层级靠底色区分而非重阴影）：

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--color-bg-page` | `#F5F6F8` | 页面底色 |
| `--color-bg-card` | `#FFFFFF` | 卡片/表格容器 |
| `--color-sidebar` | `#1F2D3D` | 后台侧边栏深色底 |
| `--color-text-primary` | `#1F2329` | 主文字（对白底对比度 14:1，远超 AA） |
| `--color-text-regular` | `#4E5969` | 正文 |
| `--color-text-secondary` | `#86909C` | 辅助说明 |
| `--color-text-placeholder` | `#C0C4CC` | 占位 |
| `--color-border` | `#E5E6EB` | 分割线、表格线 |
| `--color-border-dark` | `#C9CDD4` | 输入框边框 |

> 验收要求：所有正文文字与背景对比度 ≥ 4.5:1（WCAG AA）；大字号/图标 ≥ 3:1。深色侧边栏上的文字单独校验。

### 2.2 字体与字号

- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`（系统字体，零加载成本，不引入 Web 字体）
- 数据、编号、时间：使用等宽数字（`font-variant-numeric: tabular-nums`），防止表格列抖动
- 字阶（后台 / 小程序）：

| 用途 | 后台 | 小程序 | 字重 |
|---|---|---|---|
| 页面标题 | 18px | 20px(40rpx) | 600 |
| 卡片/区块标题 | 16px | 17px(34rpx) | 600 |
| 正文/表格 | 14px | 15px(30rpx) | 400 |
| 辅助说明 | 12px | 13px(26rpx) | 400 |
| 数据大字（Dashboard） | 28px | 32px | 600 |

- 行高：正文 1.5–1.6；标题 1.3

### 2.3 间距、圆角、阴影、层级

- **间距**：4 的倍数体系：`4 / 8 / 12 / 16 / 24 / 32`（小程序对应 rpx×2）。卡片内边距 16/24，区块间距 16，页面边距 16/24。
- **圆角**：小元素（按钮、输入框、标签）`4px`；卡片 `6px`；小程序卡片 `8px`（16rpx）。全系统统一，禁止随机圆角值。
- **阴影**：只有两级——卡片静止态无阴影（靠底色区分）；浮层（下拉、对话框）`0 4px 16px rgba(0,0,0,0.08)`。
- **z-index 标尺**：`0 内容 / 10 吸顶 / 100 固定导航 / 1000 抽屉对话框 / 2000 消息提示`，中间不允许出现任意值。

## 三、Web 管理后台设计

### 3.1 整体布局骨架

```
┌──────────────┬────────────────────────────────────────┐
│              │ 顶栏：面包屑 | 全屏 消息🔔 头像▾          │
│   侧边栏      ├────────────────────────────────────────┤
│  （深色        │ 标签页 Tags View：工作台 | 任务监控 ×    │
│  220px，      ├────────────────────────────────────────┤
│  可折叠64px） │                                        │
│              │            内容区（灰底白卡片）           │
│   Logo        │                                        │
│   工作台      │                                        │
│   巡检管理 ▾  │                                        │
│   异常工单    │                                        │
│   ...        │                                        │
└──────────────┴────────────────────────────────────────┘
```

- **侧边栏**：深色 `#1F2D3D`，图标 + 文字（不允许纯图标导航）；当前项高亮（主色左条 + 浅色底）；折叠时 hover 弹出浮层菜单；菜单由后端按角色权限动态下发。
- **顶栏**：左侧面包屑（三级以上层级必须），右侧全屏、消息通知（带未读角标）、用户下拉（个人中心 / 修改密码 / 退出登录——退出等危险项与其他项分隔线隔开）。
- **Tags View**：打开的页面以标签页驻留，切换不丢筛选条件；右键支持关闭其他/关闭全部。
- 最小适配宽度 1280px；表格列多时允许表格内横向滚动，**页面整体不允许横向滚动**。

### 3.2 通用页面范式（所有列表页严格遵守）

```
┌─ 搜索区（白卡片）──────────────────────────┐
│ 小区[▾] 巡检员[  ] 日期[  ~  ]  [查询][重置] │
├─ 工具栏 ──────────────────────────────────┤
│ [+ 新增] [批量生成二维码] [导出]      刷新⚙密度 │
├─ 表格 ────────────────────────────────────┤
│ □ | 点位名称 | 小区 | 打卡方式 | 状态 | 操作   │
│ ...（斑马纹，行高 48px，hover 浅底）          │
├───────────────────────────────────────────┤
│              共 128 条  < 1 2 3 ... > 20条/页 │
└───────────────────────────────────────────┘
```

- 查询按钮为主按钮，每页**只有一个主色主按钮焦点**；
- 新增/编辑统一用**抽屉**（字段 ≤6 个）或**对话框**（字段多），不用跳转页面，保持上下文；
- 删除行内操作红色文字，点击后 `MessageBox` 二次确认："删除后不可恢复，请输入/确认…"；
- 表格操作列固定右侧，宽度刚好放下按钮；超过 3 个操作收进"更多 ▾"；
- 空状态：插画不需要，用图标 + 一句指引 + 主操作按钮（如"暂无点位，[新增点位]"）；
- 加载超过 300ms 显示骨架屏/表格 loading，禁止白屏无反馈；
- 所有异步按钮点击后立即进入 loading + 禁用，防止重复提交。

### 3.3 工作台（Dashboard）

- 第一行 4 个统计卡：**今日任务完成率**（环形进度）、**进行中任务**、**待处理异常**（有值时红色高亮）、**逾期任务**；卡片可点击下钻到对应列表。
- 第二行：近 7 天巡检完成率趋势（折线图）+ 各小区今日执行情况（横向条形图，按完成率排序，未完成标橙）。
- 第三行：最新异常工单列表（前 5 条）+ 今日任务执行动态时间线。
- 所有图表遵循 §五 图表规范；无数据时显示空状态而非空白坐标轴。

### 3.4 巡检管理（核心页）

**点位管理**
- 左侧小区/楼栋树，右侧点位表格；支持批量导入、批量生成二维码（导出 A4 排版 PDF 直接打印张贴）。
- 点位表单：地图选点（腾讯地图组件拾取坐标）+ 围栏半径滑块（50–500m，地图实时画圈预览）+ 打卡方式单选（扫码/围栏/任一/两者）+ 必拍项动态列表。

**任务监控（管理人员最常用的页面，重点设计）**
```
┌ 任务卡片：XX小区日常巡检 · 张三 · 进度 9/12 ────────┐
│ ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁ 75%                                 │
├ 点位时间线（按路线顺序）─────────────────────────────┤
│ ✅ 08:32  1号楼大堂      扫码 · 距点位3m   [照片]     │
│ ✅ 08:41  配电房         围栏 · 距点位8m   [照片]     │
│ ⚠️ 09:05  地下车库A区    围栏 · 距126m 疑似作弊 [照片]│
│ ❌ --:--  消防泵房       未打卡                       │
│ ...                                                 │
└─────────────────────────────────────────────────────┘
```
- 状态图标 + 颜色双重编码（图标为主、颜色为辅，色盲可辨）；
- 点击"照片"弹出照片墙：带水印缩略图，点击进入查看器（放大、左右切换、显示 EXIF 校验结果与打卡元数据）；
- 列表页用状态筛选 Tab（全部/进行中/已完成/有缺卡/有异常/疑似作弊）。

**巡检记录**：通用列表范式，行点击展开打卡明细（照片、坐标地图小窗、水印信息）。

### 3.5 异常工单

- 顶部状态 Tab（待派单 N / 处理中 N / 待复核 N / 已关闭）带数量角标，主管登录默认落在"待派单"；
- 详情页为**左右结构**：左侧异常信息（照片、点位、上报人、描述），右侧**流转时间线**（上报 → 派单 → 处理反馈 → 复核关闭，每步含操作人、时间、照片）；
- 派单为对话框选人；驳回复核必须填写原因；
- 打印/导出保留完整时间线，可直接归档给甲方。

### 3.6 统计分析

- 报表页统一"筛选条 + 指标卡 + 图表 + 明细表 + 导出"五段式；
- 巡检员绩效表支持按列排序；覆盖率、及时率、异常率三指标并列；
- 导出按钮 loading 防抖，大文件异步生成后消息中心通知下载。

### 3.7 系统管理

- 用户/角色/菜单/字典/参数五页全部走通用列表范式；
- 角色权限分配：左侧角色列表，右侧**菜单权限树（父子联动勾选）+ 数据范围单选（全部/按小区多选）**；
- 操作/登录日志只读列表，支持导出，不提供任何编辑入口。

## 四、微信小程序端设计（巡检员）

设计基调：**大字、大按钮、单手操作、户外强光可读**。巡检员多为中年员工，戴手套/手湿/边走边操作是常态。

### 4.1 结构与导航

底部 TabBar 三个（≤5 原则）：**任务** | **消息** | **我的**。图标 + 文字，不用纯图标。

### 4.2 关键页面

**今日任务（首页）**
- 顶部：日期 + 今日总进度环（已检 9/12 点）；
- 任务卡片列表：小区名、点位进度条、要求时段、状态标签（待开始/进行中/已完成/已逾期）；
- 进行中的任务排在最前并加大主按钮"继续巡检"；
- 离线时顶部出现黄色横幅："当前离线，打卡将在恢复网络后自动上传（已暂存 2 条）"。

**巡检执行页（点位路线）**
```
┌──────────────────────────┐
│ XX小区 · 日常巡检  9/12    │
│ ▓▓▓▓▓▓▓▓▓▓░░░░░ 75%      │
├──────────────────────────┤
│ ✅ 1号楼大堂    08:32 正常 │
│ ✅ 配电房       08:41 正常 │
│ 🔵 地下车库A区  [去打卡]   │ ← 当前点位高亮放大
│ ⚪ 消防泵房                │
│ ⚪ 电梯机房                │
└──────────────────────────┘
```
- 当前待打卡点位卡片展开为最大视觉焦点；已完成的折叠为一行；
- 点位行点击进入打卡流程，返回时列表保持滚动位置与进度。

**打卡页（全系统最重要的一屏）**
```
┌──────────────────────────┐
│  地下车库A区               │
│  📍 距点位 8m（围栏内 ✓）   │ ← 超范围时红色提示并禁提交
│                          │
│  必拍项：                  │
│  [📷 配电箱]  已拍 ✓       │
│  [📷 消防栓]  点击拍摄      │
│                          │
│  巡检结果： ○正常 ○异常    │
│  （选异常展开描述+拍照）    │
│                          │
│  ┌────────────────────┐  │
│  │     提 交 打 卡      │  │ ← 48px+ 主按钮，底部固定
│  └────────────────────┘  │
└──────────────────────────┘
```
- 拍照按钮高度 ≥ 56px，整个卡片区域可点（触控目标 ≥ 44pt，间距 ≥ 8px）；
- 点击拍摄直接唤起相机（`wx.chooseMedia` 限定 `sourceType: ['camera']`），拍后立即本地预览 + 后台压缩上传，弱网先存本地队列；
- GPS 校验实时反馈：进入围栏变绿"可打卡"，超范围红色文字说明还差多少米，并按点位配置允许或禁止提交；
- 扫码点位：页面中部大按钮"扫码打卡"调起 `wx.scanCode`，码值与点位不匹配时震动 + 红色提示；
- 提交成功：打勾动画（≤300ms）+ 震动反馈 + 自动跳到下一点位，**两步操作完成一次打卡**是效率目标。

**异常上报**：打卡页内联展开（渐进披露，不跳页面）：描述输入、照片（最多 6 张）、紧急程度选择，提交后 toast"工单已生成 WX20260805-003"。

**我的工单 / 消息 / 个人中心**：标准列表 + 详情时间线；消息支持订阅消息授权引导。

### 4.3 小程序专项要求

- 触控目标 ≥ 44×44pt（约 88rpx），相邻目标间距 ≥ 8px；
- 所有点击 100ms 内有视觉反馈（`hover-class` 按压态）；
- 状态切换动画 150–300ms，只动 transform/opacity；
- 适配刘海屏/底部安全区（`safe-area-inset-bottom`），主按钮不压手势条；
- 户外可读：正文 ≥ 15px(30rpx)，纯白卡片 + 深色文字，不用浅灰小字；
- 列表超过 50 项分页加载；照片缩略图走 CDN 小图，点击才加载原图。

## 五、图表规范（ECharts）

| 场景 | 图表 | 说明 |
|---|---|---|
| 趋势（完成率 7 天/30 天） | 折线图 | 单系列主色，面积填充 10% 透明度，不加粗渐变 |
| 小区间对比 | 横向条形图 | 类目 >5 时不用饼图；值直接标注在条端 |
| 占比（正常/异常/缺卡） | 环形图 | ≤5 类；中心显示总数 |
| 任务进度 | 进度条/环形进度 | 不用图表库，原生组件 |
| 点位执行情况 | 不用图，用状态时间线 | 图形无法表达顺序与状态细节 |

通用规则：图例常显且可点击切换系列；悬浮 tooltip 显示精确值；坐标轴标签不旋转不截断（移动端横向条图优先）；网格线用 `#EBEEF5` 低对比度；图表加载用骨架屏，失败给重试按钮；每张图配一句文字结论（无障碍摘要）；颜色禁止红绿单独配对（配图标/文字）。

## 六、交互与反馈规范（两端通用）

- **按钮**：主/次/文字三级；异步操作 loading + 禁用；危险操作红色且二次确认（确认框说明后果，按钮文案写动作本身如"删除"而非"确定"）。
- **表单**：label 必现（不允许只用 placeholder）；失焦校验，错误红字显示在字段下方并说明如何修正；必填红星；提交失败自动聚焦第一个错误字段；长表单离开前提示未保存。
- **反馈**：操作成功用轻提示（3 秒自动消失）；失败用可停留的错误提示 + 重试入口；流程性结果（工单提交）跳结果页。
- **空状态**：图标 + 一句话说明 + 主操作按钮，三件套齐全，禁止空白页。
- **加载**：>300ms 显示骨架屏；>10s 给取消/重试；分页加载有"没有更多了"终态。
- **返回**：浏览器返回/小程序返回行为可预期，返回列表保留筛选与滚动位置。
- **文案**：全系统统一术语表（点位/任务/打卡/工单），按钮用动词（"提交打卡"而非"确定"），错误提示说人话（"网络异常，已为您保存，将自动重试"而非"error 500"）。

## 七、质量验收清单（UI 走查用）

- [ ] 无 emoji 充当功能图标，图标统一 Element Plus Icons / 小程序统一线性图标族
- [ ] 组件内无裸色值，全部走设计令牌；hover/按压/禁用三态齐全
- [ ] 正文对比度 ≥ 4.5:1；功能色均配图标或文字
