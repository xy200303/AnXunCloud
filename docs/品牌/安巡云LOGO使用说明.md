# 安巡云 LOGO

## 设计寓意

- **建筑字母 A**：以安巡云英文首字母为骨架，提炼屋顶、楼宇与空间秩序，避免通用盾牌图形。
- **横向门楣**：代表平台把人、点位、任务和工单统一纳入一套管理秩序。
- **向上弧线**：代表云端数据、巡检轨迹和持续运营；末端圆点是可追溯的现场节点。
- **留白与细节**：参考高端地产与企业服务品牌的克制处理，保证小尺寸识别力和长期耐看度。

## 色彩

| 颜色 | 色值 | 用途 |
| --- | --- | --- |
| 品牌蓝 | `#2B5AED` | 主按钮、主标强调、导航状态 |
| 深海军蓝 | `#16324F` | 图形骨架、深色导航、正文标题 |
| 香槟金 | `#C8A56B` | 门楣、云轨迹和高端强调 |
| 反白米 | `#F7F3EB` | 深色背景上的主标反白 |
| 辅助灰蓝 | `#64748B` | 英文、副标题与说明文字 |

## 文件

- `frontend/public/brand/anxuncloud-mark.svg`：可缩放图形标。
- `frontend/public/brand/anxuncloud-mark-reverse.svg`：深色背景使用的反白图形标。
- `frontend/public/brand/anxuncloud-lockup.svg`：图形标 + 中英文标准组合。
- `frontend/public/brand/anxuncloud-app-icon.svg`：应用图标矢量源文件。
- `backend/assets/logo.png`：二维码与后端图片水印使用的 512px PNG。
- `app/static/brand/anxuncloud-mark.png`：移动端登录页使用的 PNG。

## 使用规则

图形标四周至少保留图形宽度 1/5 的留白；不要拉伸、旋转、添加阴影或更改建筑字母与云轨迹的比例。深色背景优先使用反白版，浅色背景使用标准深海军蓝版。
