# 安巡云 · 政府补贴与项目申报指南

> 版本：v1.0 日期：2026-08
> 适用项目：安巡云 AnXunCloud —— AI 智能物业巡检闭环管理系统
> （Go + Vue3 + 微信小程序，AI 视觉识别设施状态，多租户 SaaS）

## 〇、项目政策定位（申报时使用的"赛道话术"）

| 维度 | 定位 |
|---|---|
| 行业赛道 | 人工智能 + 城市治理 / 安全生产 / 智慧物业 |
| 技术关键词 | 多模态视觉识别、大模型应用、SaaS 平台、移动互联网 |
| 政策挂钩点 | 武汉市促进人工智能产业发展若干政策措施（武政规〔2025〕3 号）；湖北省 51020 现代产业集群（软件和信息服务）；红色物业 / 党建引领基层治理 |
| 落地证明 | 已有真实甲方（单小区约 3500 点位/月、2 名巡检员）实际运行，AI 识别闭环可用 |

## 一、总体路线图

```
第一步（本月）     第二步（3个月内）    第三步（本年度）      第四步（1~2年）
────────────────  ──────────────────  ──────────────────  ──────────────────
科技型中小企业     双软评估              AI 典型应用场景      高新技术企业
入库（科小）      （软件产品+企业）      遴选（重点申报）     认定
+ 软著申请        → 即征即退/两免三减半  + 科技成果转化项目   → 创新型中小企业
+ 研发费用辅助账    研发费用加计扣除       + 各区 AI 专项        → 专精特新
```

原则：**资质是入场券，先做科小和软著；税收减免不依赖评审，财务直接享受；场景类项目资金最对口，重点投入。**

## 二、资质类（入场券，按优先级）

### 1. 科技型中小企业入库 ★最优先

| 项 | 内容 |
|---|---|
| 支持内容 | 研发费用加计扣除比例提升至 100%；入库编号是申报武汉市/各区科技计划、创新基金的前置条件；部分区对首次入库有资金奖励 |
| 申请条件 | ① 在中国注册的居民企业；② 职工总数 ≤500 人、年销售收入 ≤2 亿、资产总额 ≤2 亿；③ 产品服务不属于国家禁止/限制/淘汰类；④ 无重大安全/质量事故、无严重失信；⑤ 综合评价得分 ≥60 分（科技人员、研发投入、科技成果三类指标），或符合直通车条件（有高企证书、近五年获国家级科技奖励、拥有有效发明专利等） |
| 申请流程 | 科技部政务服务平台（fuwu.most.gov.cn）"科技型中小企业评价"系统 → 企业自评填报 → 区县科技部门初审 → 省级公示入库，全程线上 |
| 时间窗口 | 常年受理、分批公示（湖北一般每月一批，具体以当年通知为准） |
| 准备材料 | 营业执照、上年度财务报表、人员花名册、研发项目情况、知识产权证明（软著/专利） |

### 2. 软件著作权 + 双软评估

| 项 | 内容 |
|---|---|
| 支持内容 | **软件产品增值税即征即退**：销售自研软件产品，增值税实际税负超过 3% 的部分即征即退（财税〔2011〕100 号）。**企业所得税两免三减半**：自获利年度起第 1~2 年免征、第 3~5 年减半（财税〔2012〕27 号，"国家鼓励的软件企业"）。即征即退税款专项用于研发的，可作不征税收入 |
| 申请条件 | 软件产品登记：有自主开发的软件 + 软著证书；软件企业评估：以软件产品开发销售为主营业务，有核心关键技术（软著/专利支撑），研发人员占比、研发费用占比达标，大学专科以上学历职工占比达标 |
| 申请流程 | ① 中国版权保护中心申请软著（线上提交源代码 + 文档，普通件约 30~60 个工作日，可加急）；② 通过中国软件行业协会（或当地软协）做"软件产品评估"和"软件企业评估"，通常每季度一批 |
| 时间窗口 | 软著全年可报；双软评估按当地软协批次 |
| 准备材料 | 源代码（前后各 30 页）、操作手册/设计文档、营业执照、财务审计报告 |
| 本项目建议 | 把"AI 逐项识别引擎""巡检任务调度系统""多租户物业巡检平台"分别申请 3~5 件软著；预算允许时布局 1~2 件发明专利（如"基于多模态视觉的消防设施状态自动判定方法"） |

### 3. 高新技术企业认定

| 项 | 内容 |
|---|---|
| 支持内容 | 企业所得税 25%→15%（三年有效，复审后再延三年）；武汉市级奖励 5 万元/家，各区按不低于 1:1 配套（首次认定多数区合计 10 万+，"免申即享"直接兑付）；融资、投标、人才政策加分 |
| 申请条件 | ① 成立满 365 天；② 拥有对主要产品起核心支撑作用的 IP（软著/专利，Ⅱ类 IP 至少 6 件或Ⅰ类 1 件以上，按创新能力评价打分）；③ 研发费用占销售收入比例：营收 ≤5000 万部分 ≥5%（5000 万~2 亿 ≥4%，2 亿以上 ≥3%）；④ 科技人员占职工总数 ≥10%；⑤ 高新技术产品（服务）收入占总收入 ≥60%；⑥ 近三年无重大违法 |
| 申请流程 | 国网系统（高新技术企业认定管理工作网）注册填报 → 各区科技部门推荐 → 专家评审（含可能的现场核查）→ 认定报备公示 → 领证。武汉每年通常两批，第一批约 5~6 月、第二批约 8~9 月（以当年市科创局通知为准） |
| 准备材料 | 近三年研发费用专项审计报告、高品收入专项审计、近一年科技成果转化材料（≥15 项转化得分最佳）、人员社保清单、IP 证书、研发管理制度文件 |
| 注意 | 需提前 1 年归集研发费用数据并建辅助账，**越早开始越好** |

### 4. 创新型中小企业 → 专精特新中小企业（梯度培育）

| 项 | 内容 |
|---|---|
| 支持内容 | 省级专精特新认定后各市州有 10~30 万元奖励（如黄石 30 万）；后续可申报国家级"小巨人"（奖励更高）；融资授信、政府基金优先 |
| 申请条件 | **创新型中小企业**：常态化申报，有软著/专利等自主知识产权 + 一定的研发费用或研发人员即可，门槛低。**专精特新中小企业**：先入库创新型；成立 ≥3 年；上年度营收 ≥1000 万（或融资 ≥2000 万）；细分市场占有率排名靠前；研发费用占比 ≥3% 或 ≥100 万；主导产品收入占比 ≥70% |
| 申请流程 | 湖北省经信厅年度通知（如 2026 年已开展第八批认定）→ 企业线上申报（省中小企业公共服务平台）→ 市州经信部门初核推荐 → 省厅专家评审公示 |
| 时间窗口 | 创新型：每半年公告一批；专精特新：每年一批（上半年申报，以省经信厅通知为准） |
| 本项目建议 | 走"物业消防安全巡检"细分赛道，积累行业客户数、合同额作为市占率证明 |

## 三、资金项目类（与项目最对口的真金白银）

### 1. 武汉市人工智能典型/示范应用场景 ★重点申报

| 项 | 内容 |
|---|---|
| 支持内容 | 示范应用场景：**按项目总投入 30%、最高 100 万元**资金支持牵头单位；入选典型应用场景本身就是权威背书。2025 年已遴选 103 个典型场景（23 示范 + 80 优秀），15 个示范场景获资金 |
| 申请条件 | 在武汉注册、具有独立法人资格的企事业单位；项目为"人工智能+行业"落地应用，有实际投入、有应用成效、可复制推广；数据安全合规 |
| 申请流程 | 市经信局发布征集通知 → 企业线上申报 → 区级推荐 → 专家评审 → **场景建设投入审计** → 公示 → 资金拨付 |
| 时间窗口 | 每年一批（2025 年申报约年中，关注市经信局/市高新技术产业协会通知） |
| 本项目素材 | 真实甲方运行数据（3500 点位/月、2 名巡检员、AI 逐项识别闭环）、识别准确率、效率提升对比（巡检耗时/漏检率变化）、"红色物业"党建治理结合点、可推广性（多租户 SaaS 已支持快速复制） |
| 政策依据 | 武汉市促进人工智能产业发展若干政策措施（武政规〔2025〕3 号） |

### 2. 各区 AI 专项（按注册地选择）

| 区 | 要点 |
|---|---|
| 武昌区 | 对创新性强、示范性好的**智能体产品**最高 500 万元奖励（2026 年征求意见稿，需跟踪正式发文） |
| 硚口区 | 促进人工智能发展若干措施：算力补贴、行业大模型研发应用、AI 融合应用支持 |
| 洪山区 | AI 高质量发展措施：核心技术攻关、创新平台、企业引育、算力普惠 |
| 东湖高新区（光谷） | 国家 AI 创新应用先导区核心区，区级专项多、力度大；若为光谷注册企业可叠加 |

> 各区政策不能重复享受同一事项，申报前对照注册地逐条匹配。

### 3. 武汉市科技成果转化项目

| 项 | 内容 |
|---|---|
| 支持内容 | 市级财政资金前资助/后补助（额度以当年指南为准） |
| 申请条件 | 企业与高校院所合作转化科技成果（需有技术合同/成果证明）；同一项目负责人限报一项；当年已获市级前资助项目的企业不得再报；无逾期未验收市科技计划项目 |
| 申请流程 | 市科创局官网"项目申报与管理—在线申报"网上办事大厅 → 项目负责人填报 → 单位审核推荐 → 区科技管理部门推荐 → 评审立项（每年约 6~7 月申报） |
| 本项目路径 | 与湖北高校（图像识别/计算机视觉方向团队）共建"AI 巡检视觉算法"合作成果，再以成果转化名义申报 |

### 4. 湖北省科技计划 / 数字经济专项

省级层面每年发布各类专项申报指南（重点研发计划、数字经济高质量发展专项等），金额较大但竞争激烈，建议在拿到高企资质后申报，或作为联合单位与高校/龙头企业组队申报。

## 四、普惠性税收优惠（无需评审，财务直接享受）

| 政策 | 内容 | 操作要点 |
|---|---|---|
| 研发费用加计扣除 100% | 未形成无形资产的研发费用在据实扣除基础上再加计 100% 扣除；形成无形资产的按 200% 摊销 | 立项研发项目、建立研发费用辅助账、留存备查（立项决议、人员工时、费用归集表） |
| 软件产品增值税即征即退 | 实际税负超 3% 部分即征即退 | 先完成软著 + 软件产品评估；分产品核算销售额与进项 |
| 企业所得税两免三减半 | 获利年度起 2 免 3 减半 | 需软件企业评估；注意"获利年度"起算点规划 |
| 小微企业普惠 | 年应纳税所得额 ≤300 万部分实际税负 5% | 自动适用，注意临界点筹划 |
| 六税两费减免 | 城建税、教育费附加等减半 | 自动适用 |
| 稳岗返还 | 按上年度实缴失业保险费一定比例返还 | 免申即享（湖北已推行），确认社保账户信息 |

## 五、申报通用准备清单

**公司层面**
- [ ] 确认公司注册区（决定可叠加的区级政策），核对营业执照经营范围含"软件开发/信息技术服务"
- [ ] 梳理上年度营收、资产、职工总数、社保人数（科小/高企/专精特新的硬指标）
- [ ] 建立研发费用辅助账，制定研发项目立项制度

**知识产权层面**
- [ ] 申请 3~5 件核心软著（AI 识别引擎、巡检调度、多租户平台）
- [ ] 评估 1~2 件发明专利（AI 判定方法类）
- [ ] 商标"安巡云"已完成注册（若未注册，同步办理）

**业务证据层面**
- [ ] 整理真实甲方合同、验收材料、运行数据报告
- [ ] 量化 AI 成效：识别准确率、巡检效率提升、漏检率下降
- [ ] 保留 AI 调用成本与场景建设投入凭证（申报 AI 场景项目需投入审计）

**人员层面**
- [ ] 研发人员占比达到 10%（高企）的台账与社保对应
- [ ] 核心技术人员职称/学历材料归档

## 六、待确认信息（影响最终可申报清单）

1. 公司注册在哪个区？（武昌/硚口/洪山/光谷等区级政策差异大）
2. 公司成立时间？上年营收、资产总额、职工总数、社保人数？
3. 现有软著/专利/商标数量？
4. 是否已有高校/科研机构合作关系？
5. 公司目前是否已盈利（影响两免三减半的起算点规划）？
